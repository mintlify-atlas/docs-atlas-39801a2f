LWXGL is a lightweight C/C++ library that lets you open an X11 window, place interactive widgets, draw shapes and sprites, and handle keyboard and mouse events — all through a single, dependency-free header. Compile it once as a shared library, include `libLWXGL.h`, and you have a complete GUI toolkit in under 1,000 lines of code.

## How it works

LWXGL wraps Xlib into a small set of C functions. You create a window, populate it with elements (widgets and image canvases), attach event callbacks, and drive the loop yourself — or let `GSimpleWindowLoop` manage the frame cadence for you.

<Steps>
  <Step title="Build and install the library">
    Clone the repository and run `make && make install` to build `libLWXGL.so` and copy it to `/usr/local/lib`.
  </Step>
  <Step title="Include the header">
    Add `#include <libLWXGL.h>` to your source file. The header exposes the full public API and is compatible with both C and C++.
  </Step>
  <Step title="Create a window">
    Call `GCreateWindow(width, height, "Title", bgColor)` to open an X11 window with a fixed size and a background from the 16-color palette.
  </Step>
  <Step title="Add widgets and run the loop">
    Create text labels, buttons, inputs, and image canvases using the `GCreate*` functions, then call `GSimpleWindowLoop` to start rendering at your target FPS.
  </Step>
</Steps>

## Key features

<CardGroup cols={2}>
  <Card title="UI Widgets" icon="window">
    Text labels, buttons with hover/press states, text inputs, and rectangles — all managed by an integer element ID.
  </Card>
  <Card title="Image Canvas" icon="image">
    Create pixel buffers, write palette indices directly, and push them to the screen with `GUpdateImage`.
  </Card>
  <Card title="Drawing Primitives" icon="pen-ruler">
    Draw rectangles, circles, lines, and RLE-encoded sprites into any image canvas element.
  </Card>
  <Card title="Event System" icon="bolt">
    Attach callbacks for keypresses, mouse clicks, and window close. Query mouse position and key state at any time.
  </Card>
  <Card title="16-Color Palette" icon="palette">
    A fixed CGA-inspired palette covering black through white. Use palette indices everywhere — no hex colors needed.
  </Card>
  <Card title="Simple Loop" icon="rotate">
    `GSimpleWindowLoop` caps your frame rate, calls your per-frame callback, and tracks FPS — no manual timing required.
  </Card>
</CardGroup>
